# 🌐 Landing Page — Meu Projeto

Projeto de uma landing page desenvolvido com **HTML5 e CSS3**, com o objetivo de praticar os fundamentos do desenvolvimento front-end.

## 📌 Sobre o projeto

A página apresenta um layout com cabeçalho, menu de navegação, seção principal, cards de serviços, área de contato e rodapé com links para redes sociais.

O projeto foi desenvolvido para praticar a estruturação de páginas HTML e a estilização de componentes utilizando CSS.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox

## ✨ Seções do site

- **Cabeçalho:** logotipo e menu de navegação.
- **Hero:** título, descrição e botão de ação.
- **Serviços:** cards com títulos e descrições.
- **Contato:** seção com texto e botão para contato.
- **Rodapé:** direitos autorais e links para redes sociais.

## 📚 Conceitos praticados

- Estrutura semântica do HTML.
- Seletores, classes e identificadores CSS.
- Flexbox para alinhamento e organização.
- Espaçamentos com `margin` e `padding`.
- Bordas, cores, sombras e arredondamento.
- Efeitos de interação com `:hover`.
- Transições com `transition`.
- Organização de conteúdo em cards.

Consolidar os conhecimentos de HTML e CSS por meio da construção de páginas web, desenvolvendo habilidades de organização, estilização e estruturação de layouts.
